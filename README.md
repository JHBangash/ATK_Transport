## Pages

- **Home** — company intro, services (staff/school/airport/event transport, bus rental) and quick quote.
- **About** — company background, mission, vision, values and fleet.
- **Contact** — contact details, WhatsApp links, enquiry form and address.
- **Invoice tool** (`#/invoice`) — create and print VAT invoices, quotations, receipts and statements.

Each page sets its own title, meta description and meta keywords for Google and Bing/Azure search engines.

## Tech

- Tailwind CSS
